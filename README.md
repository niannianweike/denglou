# 登楼 · 中国诗楼地图

面向课堂和自主学习的互动课件。从地图出发，游览黄鹤楼、滕王阁、岳阳楼等十四座诗楼，在三维场景中阅读诗文、探索展陈。

[在线体验「登楼」](https://niannianweike.top/tools/denglou/)

## 本地运行

用支持 WebGL 的浏览器打开根目录的 `index.html`。也可以在项目目录启动静态服务器，再打开 `http://localhost:8000`。

```sh
python -m http.server 8000
```

无需安装前端依赖或构建。各楼的独立入口位于对应的 `*-3d/index.html`。讲解录音存放在各楼的 `audio/` 目录。
